## Hangman Game

This repository contains a complete functional Hangman game implemented in Go. The game includes:

- A word list with various programming-related terms
- Game logic for guessing letters and tracking wrong guesses
- Visual hangman drawing based on wrong guesses
- Win/loss detection
- Interactive command-line interface

The game is fully functional and can be run directly with `go run main.go`.
